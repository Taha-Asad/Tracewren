The selected direction follows the numbered feedback: **image 1's forest and cream, without the faded treatment**. Image 2 contributes clear grouping. Image 3 remains available as a simpler, two-column backup study; it is not the full prototype.

## What changed

- Solid forest navigation, clean cream surfaces, stronger text and restrained rust actions. Reduced editorial headings and repeated decoration.
- A compact boundary illustration explains the original finding. Numbered steps, readable request snippets and labelled expected/observed results keep the research readable.
- Persistent report identity, current stage and next actor/action. Tabs retain role, lifecycle and attempt; shared conversation and defender-only notes have separate lanes.
- Connected code evidence → deployment → retest. Failed attempt 1 remains visible when attempt 2 is proposed and verified.
- Completed records foreground verifier, environment, attempt and supporting evidence. Researcher verification, internal verification and unverified timeout remain distinct.
- Saved-recovery confirmation, encryption recipients, owner MFA, key recovery and role restrictions remain represented.

## Open and review

Open the v5 file in FigCraft. The selected original-report frame is ready to inspect. For the connected prototype, choose **00 · Fieldwork / Read me**, select **Start**, and enter Present. Use **Start full journey**. Role changes are explicitly labelled demo switches. The **390px full journey** entry covers submission and recovery; the separate **Narrow / retest available** start covers failed attempt 1 through verified attempt 2.

Prepared form values, service outcomes and fixture data allow the native journey to be reviewed. Actual encryption, signatures, file downloads, MFA, GitHub, network and backend authorization are outside this design prototype. The QR is a labelled public example.

## Verification and handoff

Saved-file verification covers 51 desktop actions, 29 narrow actions, 1,027 context-preserving tab links, both-attempt internal/timeout outcomes, target validity, native layout bounds and text contrast. It found **zero unexpected bounds, text-contrast failures or missing destinations** after correction. This is a design check, not browser accessibility or security certification.
