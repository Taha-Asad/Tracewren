# Research illustrations

Original, editable vector artwork for BugBountyTrack Professional v4.

- `boundary.svg`: controlled workspaces and a magnified access-boundary breach.
- `retest.svg`: inspect the deployed attempt; no result implied.
- `failed.svg`: unresolved finding and a return loop for replacement work.
- `submission.svg`: report, attached evidence and local encryption.
- `verified.svg`: retained report and a verified-outcome shield.

These are conceptual illustrations. They are not screenshots, attachment previews, additional findings or observed verification evidence. Evidence filenames, excerpts and expected/observed results remain separately labelled in the report.

The native file contains corresponding reusable `BBT/Illustration/*` components made from individually editable shapes, with colours bound to the existing semantic variables. Desktop panels give the artwork space beside useful labels; narrow layouts use a smaller illustration beside stacked checkpoint labels.

Authoritative source: `tools/design/professional-v4/illustrations.py` regenerates the SVGs and native components together.
