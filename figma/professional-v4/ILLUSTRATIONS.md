# Illustration refinement

The report now uses an original vector illustration of a magnified workspace-boundary breach as its visual focal point. Active remediation uses an inspection illustration beside the actual code, deployment and retest checkpoints. Failed retests use an unresolved mark and return loop; verified outcomes use a shield and check. Submission review and queue context use a report-and-encryption illustration.

The five illustrations share charcoal outlines, warm paper, muted sage and teal. Red is limited to the unresolved finding. Their editable source components live on the foundations page as `BBT/Illustration/*`; matching SVG source files are in `figma/assets/illustrations/`.

Artwork supports the existing content: expected and observed results, original filenames, report identity, next actions, actual remediation attempts and verifier details remain separately readable. The illustrations are conceptual artwork, not attachment previews or additional evidence.

The previous v4 native file and core screen exports are preserved under `archive/*before-illustrations*`. V3 remains preserved.
