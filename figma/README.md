# BugBountyTrack — editable UX design

Open **[BugBountyTrack-UX.figcraft](BugBountyTrack-UX.figcraft)** manually in FigCraft. Choose **00 · Start here**, select the **StartHere** frame and enter **Present / prototype mode**. In Design mode, use the numbered pages to edit real text, vectors, Auto Layout frames and component instances.

The first native edition follows your direction: a distinct security workbench connected to The Foolish Crow through graphite, warm ivory, petrol, restrained brass and a feather signature. It is not a RoostDeck theme transplant.

- **14 pages**, **10 editable wireframes**, **7 workflow maps**, **30 named prototype starts**.
- **157 product screen/state frames**, **141 contextual overlays**; **330 top-level views** including guides and wireframes. These are views/states, not 330 independent features.
- **33 source components**, **2 variant sets**, **2434 instances**, **38 text styles** and **112 variables**.
- Desktop **1440 × 900** and **1366 × 768**, compact **1024 × 768**, and mobile **390 × 844** studies.

Start with **Researcher**, **Defender** or **Organization Owner**. Account, profile, password reset, sessions, MFA, membership, key recovery, audit and capacity work are included. Commercial private programs, redacted exports, billing and platform administration are clearly separated under **11 · Planned extensions**.
